# TRADEFIND — STITCH SCREEN GENERATION PROMPT # Version 2.0 — Rewritten from scratch # 17 screens. Every one earns its place. # Design language: iOS 17 native — depth, contrast, restraint  ---  ## READ THIS FIRST — THE DESIGN PHILOSOPHY  This is not a generic mobile UI. It is a **premium iOS app** that competes with Uber, Deliveroo, and Apple Maps in terms of feel. Every design decision below has a reason. Do not substitute, simplify, or "improve" anything without understanding why it exists.  ### The one rule everything else follows  **Every screen has exactly one hero moment** — one piece of information or one interactive element that is dramatically larger, bolder, or more prominent than everything else. The user's eye lands there first and immediately understands what this screen is for.  - Tracking screen → the ETA number - Worker profile → the worker's photo + name - Dashboard live → the green "You're live" state - Home screen → the search bar - Review screen → the 5 giant stars  If you can't identify the hero moment on a screen, the screen doesn't have a clear purpose. Find it before you design anything else.  ---  ## THE DESIGN SYSTEM  ### Colours  There are only **5 colours that matter**. Everything else is derived from them.  ``` Orange        #F97316   — The brand. Used ONLY for:                           • The single primary button per screen                           • Active tab bar item                           • Key metric numbers (ETA, rating, distance)                           • The "TradeFind" wordmark in the nav bar                           • Active toggle/switch state                           NEVER use orange as a background fill on any large area.                           NEVER use orange for decorative elements.  Near-black    #111827   — All headings, primary text, important numbers Mid-grey      #6B7280   — Supporting text, labels, captions, inactive icons Light-grey    #F3F4F6   — Input backgrounds, chip backgrounds, skeleton loaders,                           the map tint, very subtle dividers Off-white     #F9FAFB   — Screen background. Every screen. Always. White         #FFFFFF   — Cards, bottom sheets, nav bar, modal surfaces ```  **Status colours — used only for their exact meaning, never decoratively:** ``` Available green   #16A34A   text / #DCFCE7 bg pill Busy grey         #6B7280   text / #F3F4F6 bg pill Live red dot      #EF4444   — just the dot, no background En route amber    #D97706   text / #FEF3C7 bg pill Warning           #D97706   text / #FFF7ED bg banner Star yellow       #FBBF24   — only for star icons ```  **What is never in this app:** - Purple, blue, pink, teal, or any other brand colour - Dark backgrounds on cards or sections - Gradients on UI elements (only on the splash hero photo overlay) - Coloured section headers - Any colour used "just to add visual interest"  ---  ### Typography  System font only — SF Pro on iOS. Do not specify a custom typeface.  ``` Display   36–48px   800 weight   — hero numbers only (ETA, distance, rating) H1        28px      700 weight   letter-spacing -0.5   — page titles H2        22px      700 weight   letter-spacing -0.3   — section titles H3        18px      600 weight                         — card titles, worker names H4        16px      600 weight                         — list item titles Body      15px      400 weight   line-height 22        — paragraphs, descriptions BodyMd    15px      500 weight                         — emphasized body Small     13px      400 weight   line-height 18        — captions, meta Caption   12px      500 weight                         — timestamps, badges Label     11px      600 weight   letter-spacing 0.6    — uppercase labels (ETA, DISTANCE)                                   ALWAYS uppercase when used as a metric label ```  **The weight contrast rule:** Hierarchy comes from font weight, not colour. A 700-weight heading next to 400-weight body creates clear hierarchy without needing different colours. Do not use colour to create hierarchy — use weight.  ---  ### Spacing  Base unit: 4px. Everything is a multiple of 4.  ``` 4px    — between icon and label, between badge elements 8px    — between related items in a row 12px   — internal card padding (tight), between list items 16px   — standard card padding, screen horizontal margin 20px   — between card sections 24px   — between major sections on a screen 32px   — between unrelated sections, top of scroll content 48px   — large breathing room, hero section padding ```  ---  ### Shapes and surfaces  **The floating nav bar** — this is the app's signature.
